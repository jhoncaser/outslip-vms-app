# Open Transaction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/transactions/open` placeholder with a real page: a table of open transaction/outslip requests, with a "+ Add Transaction" button that files a new one (Transaction Type only, in this first round).

**Architecture:** Two new Prisma models — `TransactionStatus` (a data table, not an enum, since future approval stages will vary per Matrix Type) and `Transaction` (references `MatrixType`, `TransactionStatus`, `User`). A new `POST /api/transactions` route creates rows, built retry-safe from the start (learning from the bug Matrix Type's code-generation shipped with and had to be fixed after the fact). `transactions/open/page.tsx` becomes a server component (mirroring `settings/page.tsx`) that fetches open transactions plus the Matrix Type list, and renders a new `TransactionsView` client component: a table plus an add-modal, same shape as `SettingsView`.

**Tech Stack:** Next.js App Router, Prisma/PostgreSQL (Neon), Zod, Vitest + Testing Library.

## Global Constraints

- Filing a transaction is open to **any authenticated user** — no permission gate beyond having a valid session (confirmed: "the add button should be accessible to all").
- This round captures **exactly one field**: Transaction Type, a dropdown sourced from the existing `MatrixType` table. No other fields (date/time, destination, remarks, etc.) — deferred to a later round.
- Transaction codes auto-generate as `` `OT-${String(count + 1).padStart(3, "0")}` `` — **must** use a bounded retry loop that recomputes `count()` on each attempt and inspects `err.meta.target` on `P2002`, exactly like the fixed version of `app/api/matrix-types/route.ts`. Do not ship the naive `count()`-then-`create()` version — that bug already happened once on this branch and was fixed after the fact.
- Only one `TransactionStatus` row is seeded now: `"Open"`. No other stages (Posted, 1st/2nd/3rd Level Approver, etc.) and no Settings UI to manage this table — both explicitly deferred.
- No approval-routing logic and no Post/Approve action buttons in this round — deferred, the user will provide that separately.
- `Department`/`BusinessUnit`/`Location`/`MatrixType` models are **not modified** by this plan.

Create `app/api/transactions/route.ts`:

```ts
import { NextRequest, NextResponse } from "next/server";
import { Prisma } from "@prisma/client";
import { prisma } from "@/lib/prisma";
import { verifySessionToken, SESSION_COOKIE_NAME } from "@/lib/auth/session";
import { transactionSchema } from "@/lib/validation/transaction";

const MAX_CODE_ATTEMPTS = 5;

export async function POST(request: NextRequest) {
  const token = request.cookies.get(SESSION_COOKIE_NAME)?.value;
  const session = token ? await verifySessionToken(token) : null;

  if (!session) {
    return NextResponse.json({ error: "Not authenticated" }, { status: 401 });
  }

  const body = await request.json();
  const parsed = transactionSchema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json({ error: "Invalid request" }, { status: 400 });
  }

  const openStatus = await prisma.transactionStatus.findUniqueOrThrow({
    where: { name: "Open" },
  });

  for (let attempt = 0; attempt < MAX_CODE_ATTEMPTS; attempt++) {
    const count = await prisma.transaction.count();
    const transactionCode = `OT-${String(count + 1).padStart(3, "0")}`;

    try {
      const created = await prisma.transaction.create({
        data: {
          transactionCode,
          matrixTypeId: parsed.data.matrixTypeId,
          statusId: openStatus.id,
          creatorId: session.sub,
        },
      });
      return NextResponse.json(created, { status: 201 });
    } catch (err) {
      if (err instanceof Prisma.PrismaClientKnownRequestError && err.code === "P2002") {
        const target = err.meta?.target;
        const fields = Array.isArray(target) ? target : [];
        if (fields.includes("transactionCode")) {
          continue;
        }
      }
      if (err instanceof Prisma.PrismaClientKnownRequestError && err.code === "P2003") {
        return NextResponse.json(
          { error: "Invalid transaction type" },
          { status: 400 }
        );
      }
      throw err;
    }
  }

  return NextResponse.json(
    { error: "Could not generate a unique transaction code, please retry" },
    { status: 409 }
  );
}
```
